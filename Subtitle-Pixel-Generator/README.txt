ENG: YOUTUBE SUBTITLE PIXEL GENERATOR

To start:
1. Extract/place these files in a single folder
2. Double-click `start.bat`
3. The first run will install Pillow, then the program will open

Requires Python 3.10+ with Tkinter (the standard Windows Python installer usually includes Tkinter)

Features:
- Supports PNG/JPG/JPEG/WEBP/BMP/GIF
- Set a "Before" time for images; subsequent elements shift automatically
- GIFs use native frame delays
- Delete and reorder elements
- █ mode or character mode
- Editable character set
- Any resolution (e.g., 32x12)
- Save XML in transcript/text format

RU: Генератор пиксельных субтитров для YouTube

Запуск:
1. Распакуй/положи эти файлы в одну папку
2. Дважды кликни start.bat
3. Первый запуск установит Pillow, дальше откроется программа

Нужен Python 3.10+ с Tkinter (обычный установщик Python для Windows обычно содержит Tkinter)

В программе:
- PNG/JPG/JPEG/WEBP/BMP/GIF
- для картинок задаётся «До», последующие элементы автоматически сдвигаются
- GIF использует родные задержки кадров
- удаление и перестановка элементов
- режим █ или символы
- редактируемый набор символов
- любое разрешение, например 32x12
- сохранение XML в формате transcript/text
